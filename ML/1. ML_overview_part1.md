# ML 개요 (Part 1) 정리

## 1. ML이란?

머신러닝은 **데이터로부터 학습할 수 있도록 컴퓨터를 프로그래밍하는 과학**이다.

대표적인 정의 두 가지:

- **Arthur Samuel (1959):** 명시적으로 프로그래밍하지 않아도 컴퓨터가 스스로 학습할 수 있게 하는 연구 분야
- **Tom Mitchell (1997):** 어떤 task T에 대해, 경험 E를 통해 성능 지표 P가 향상될 때, 그 프로그램이 학습한다고 말함

> 💡 **Mitchell 공식 외우기: T / E / P**
> 
> - **T** (Task): 수행할 작업
> - **E** (Experience): 학습에 사용하는 데이터(경험)
> - **P** (Performance): 성능 측정 지표

---

## 2. 핵심 용어

| 용어                             | 설명                                                             |
| ------------------------------ | -------------------------------------------------------------- |
| **Training Set**               | 시스템이 학습에 사용하는 예제들의 집합                                          |
| **Training Instance (Sample)** | 학습 데이터 하나하나의 단위                                                |
| **Model**                      | 학습하고 예측을 수행하는 ML 시스템의 핵심 부분 (예: neural network, random forest) |

---

## 3. Spam Filter 예시로 보는 T/E/P

스팸 필터를 Mitchell의 정의에 대입하면:

- **T:** 새 이메일이 스팸인지 판별
- **E:** 스팸/햄(정상 메일) 레이블이 달린 학습 데이터
- **P:** 정확도 (correctly classified emails의 비율)

---

## 4. 전통적 프로그래밍 vs ML

### 전통적 방식

1. 스팸의 패턴 파악 (특정 단어/구절 식별)
2. 각 패턴에 대한 탐지 알고리즘 작성
3. 테스트 → 반복

**한계점:**

- 문제가 복잡해질수록 규칙 목록이 방대해져 유지보수가 어려움
- 스패머가 우회 패턴을 쓰면 (예: "4U" → "For U") 규칙을 계속 새로 써야 함
- 변화에 적응하지 못함

### ML 방식

- 스팸/햄 데이터를 학습시키면 모델이 **자동으로** 스팸 지표가 되는 단어/패턴을 학습
- 스패머가 우회 패턴을 쓰면 **인간 개입 없이** 자동 적응
- 코드가 짧고, 유지보수가 쉽고, 더 정확함

### 핵심 차이

```
[전통적 프로그래밍]
Rules + Data → 컴퓨터 → Answers

[머신러닝]
Data + Answers(training set) → 컴퓨터 → Rules
```

## 5. ML을 사용해야 하는 경우 (시험 단골!)

| 상황                                       | 이유                            |
| ---------------------------------------- | ----------------------------- |
| 규칙이 너무 많고 복잡한 문제                         | ML 모델이 코드를 단순화하고 더 좋은 성능을 냄   |
| 전통적 방법으로 해결책이 없는 복잡한 문제                  | ML 기법이 해결책을 찾을 수 있음           |
| 환경이 계속 변하는 경우 (Fluctuating environments) | 새 데이터로 쉽게 재학습 가능, 항상 최신 상태 유지 |
| 대용량 데이터에서 인사이트를 얻고 싶을 때                  | Data Mining — ML이 강점을 보임      |

> **Data Mining:** 대량의 데이터에서 숨겨진 패턴을 발굴하는 것, ML이 특히 뛰어남

---

## 6. ML의 장점 정리

- **복잡한 문제 해결:** 전통적 방법이 없거나 너무 복잡한 경우 (예: 음성 인식 - 수천 단어 × 수백만 명 × 수십 개 언어)
- **자동 적응 (Automated Learning):** 데이터가 업데이트되면 모델도 자동으로 재학습 가능
- **인간 학습 지원:** 학습된 모델을 분석하면 데이터에서 **예상치 못한 상관관계나 새 트렌드** 발견 가능

## 8. Generative AI

**정의:** 대규모 데이터셋으로 학습된 모델을 통해 **새로운 콘텐츠(텍스트, 이미지, 음악 등)를 생성**하는 AI의 하위 분야

### 핵심 기술 3가지

| 기술                                         | 설명                    | 주요 활용     |
| ------------------------------------------ | --------------------- | --------- |
| **Neural Networks** (Transformer 기반)       | 딥러닝 모델, 복잡한 추론과 맥락 이해 | 텍스트 생성    |
| **GANs** (Generative Adversarial Networks) | 두 모델이 경쟁하며 학습         | 이미지/영상 생성 |
| **VAEs** (Variational Autoencoders)        | 다양한 생성 작업에 활용         | 이미지 편집/합성 |

### 최근 발전

- **Transformer 모델:** 단순 텍스트 생성 → 복잡한 추론과 문맥 이해로 진화
- **멀티모달 모델:** 텍스트 + 이미지 + 오디오를 함께 처리 (GPT-5, Google DeepMind 등)

### Generative AI 응용 분야

|분야|주요 도구|
|---|---|
|텍스트 생성|GPT-5, Google Gemini, Naver CLOVA X, DeepSeek|
|이미지/영상 생성|GAN 기반 - DeepArt, RunwayML, Artbreeder|
|음악/오디오 생성|OpenAI Jukebox, Amper Music, AIVA|
|AI 코드 생성|GitHub Copilot|
