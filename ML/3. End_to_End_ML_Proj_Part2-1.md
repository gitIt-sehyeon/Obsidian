## 4. 머신러닝 알고리즘을 위한 데이터 준비

### 데이터 준비 과정 자동화

데이터 준비 과정 전체를 함수로 구현해두는 것이 바람직한 이유:

- 업데이트된 데이터셋에도 **동일한 변환 과정을 반복** 적용 가능
- 함수 라이브러리로 구축해 **다른 프로젝트에서 재사용** 가능
- 실제 라이브 시스템에서 새 데이터를 모델에 주입하기 전에 사용 가능
- 여러 변환 방법을 시도해보면서 **최적 조합 탐색** 용이

housing = strat_train_set.drop("median_house_value", axis=1)

전처리 과정 분류:

- 기존 특성 조합으로 새 특성 추가

**범주형 특성 전처리:**

- 원-핫 인코딩

### 데이터 정제 (Data Cleaning) - 결측치 처리

**왜 결측치 처리가 필요한가?** → ML 알고리즘은 결측치가 포함된 데이터를 다루지 못하기 때문에 **반드시 처리 필요**

이 데이터셋에서 `total_bedrooms` 특성에 207개 결측치(NaN) 존재.

**결측치 처리 3가지 방법:**

|옵션|방법|코드|
|---|---|---|
|옵션 1|결측치 있는 샘플(행) 전체 제거|`housing.dropna(subset=["total_bedrooms"], inplace=True)`|
|옵션 2|결측치 있는 특성(열) 전체 삭제|`housing.drop("total_bedrooms", axis=1)`|
|옵션 3|결측치를 특정 값(평균/중간값/0 등)으로 채우기|`housing["total_bedrooms"].fillna(median, inplace=True)`|

이 프로젝트에서는 **옵션 3 (중간값으로 채우기)** 을 사용.

---

### SimpleImputer를 활용한 결측치 처리

사이킷런이 제공하는 변환기(transformer) 클래스로 옵션 3을 구현할 수 있어.

python

```python
from sklearn.impute import SimpleImputer

imputer = SimpleImputer(strategy="median")
```

**주의:** median strategy는 **수치형 특성에만** 사용 가능하므로, 텍스트 타입인 `ocean_proximity`를 제거한 데이터 사본 생성 필요:

python

```python
housing_num = housing.select_dtypes(include=[np.number])
```

**SimpleImputer 사용 순서:**

1. `imputer.fit(housing_num)` → 각 특성별 median 값 계산, `statistics_` 인스턴스 변수에 저장
2. `X = imputer.transform(housing_num)` → 결측치를 해당 특성의 median으로 채움

**SimpleImputer strategy 종류:**

|strategy|설명|수치형만?|
|---|---|---|
|`"median"`|중간값으로 채움|✅ 수치형만|
|`"mean"`|평균값으로 채움|✅ 수치형만|
|`"most_frequent"`|최빈값으로 채움|❌ 범주형도 가능|
|`"constant"` + `fill_value=..`|지정한 값으로 채움|❌ 범주형도 가능|

---

### 사이킷런의 3가지 클래스 유형 (시험 포인트!)

이 부분이 개념적으로 중요해. 정확하게 구분할 수 있어야 해.

#### ① Estimator (추정기)

- 데이터셋으로부터 **모델 파라미터를 추정**하는 객체
- `fit(..)` 함수 호출로 파라미터 추정 실행
- 예: `SimpleImputer` → 훈련셋으로부터 각 특성별 median 값을 학습

> **모델 파라미터** vs **하이퍼파라미터** 구분:
> 
> - **모델 파라미터**: 데이터로부터 학습되는 값. e.g., 각 특성의 median 값 → `imputer.statistics_`로 접근 (변수명 끝에 **밑줄** 붙음)
> - **하이퍼파라미터**: 학습 과정을 가이드하는 설정값. e.g., `strategy="median"` → `imputer.strategy`로 접근

#### ② Transformer (변환기)

- estimator 중 데이터 **변환 작업도 수행**하는 객체
- `transform(..)` 함수 호출로 변환 실행, 변환된 데이터셋 반환
- `fit_transform()` 함수도 제공 (fit + transform 순차 실행, 최적화 적용으로 더 효율적)
- 예: `SimpleImputer`는 estimator이면서 동시에 transformer에도 해당

#### ③ Predictor (예측기)

- 새로운 데이터 샘플에 대해 **예측을 만드는** 객체
- `predict(..)` 함수: 샘플을 입력받아 예측값 반환
- `score(..)` 함수: 테스트셋을 이용해 예측 성능 측정
- 예: `LinearRegression` 객체

**사이킷런 인스턴스 변수 접근 규칙:**

- 하이퍼파라미터: `imputer.strategy` (밑줄 없음)
- 학습된 모델 파라미터: `imputer.statistics_` (마지막에 **밑줄** 추가)

### 범주형 특성(Categorical Features) 다루기

대부분의 ML 알고리즘은 숫자만 다룰 수 있어. 따라서 텍스트인 `ocean_proximity` 특성을 숫자로 변환해야 함.

#### OrdinalEncoder - 단순 수치화

python

```python
from sklearn.preprocessing import OrdinalEncoder
```

범주를 그냥 0, 1, 2, 3, 4로 매핑하는 방식.

|범주|수치값|
|---|---|
|<1H OCEAN|0|
|INLAND|1|
|ISLAND|2|
|NEAR BAY|3|
|NEAR OCEAN|4|

**문제점:** ML 알고리즘은 **가까운 수치값이 더 비슷한 의미**를 갖는다고 간주함.

- 범주 0(<1H OCEAN)과 1(INLAND)보다 0과 4(NEAR OCEAN)이 의미적으로 더 비슷하지만
- 숫자상으로는 0과 1이 더 가깝게 처리됨 → **잘못된 학습 유발 가능**

> 단, bad/avg/good/excellent처럼 **순서가 의미 있는** 범주형 특성의 경우에는 OrdinalEncoder가 적합함.

---

#### One-hot Encoding (원-핫 인코딩)

범주 간에 순서 관계가 없을 때 OrdinalEncoder의 문제를 해결하는 방법.

**원리:** 범주형 특성 1개를 범주 수만큼의 더미(dummy) 특성으로 대체. 해당 범주이면 1, 아니면 0.

예: ocean_proximity (5개 범주) → 5개 더미 특성으로 대체

|샘플|원래 값|<1H OCEAN|INLAND|ISLAND|NEAR BAY|NEAR OCEAN|
|---|---|---|---|---|---|---|
|13096|NEAR BAY|0|0|0|**1**|0|
|14973|<1H OCEAN|**1**|0|0|0|0|
|3785|INLAND|0|**1**|0|0|0|

**사이킷런의 OneHotEncoder 사용:**

python

```python
from sklearn.preprocessing import OneHotEncoder

cat_encoder = OneHotEncoder()
housing_cat_1hot = cat_encoder.fit_transform(housing_cat)
```

**sparse 인자 설정:**

|sparse 설정|반환 형태|언제 쓰나?|
|---|---|---|
|`sparse=True` (기본값)|SciPy sparse matrix|범주 수가 매우 많을 때 효율적 (0의 위치 대신 1의 위치만 저장)|
|`sparse=False`|NumPy 이차원 배열|일반적으로 다루기 편할 때|

**Sparse matrix란?** 대부분 0으로 채워진 행렬을 효율적으로 표현하는 방식 (행렬 내 소수의 1의 위치만 저장).

**학습된 범주 확인:**

python

```python
cat_encoder.categories_
# [array(['<1H OCEAN', 'INLAND', 'ISLAND', 'NEAR BAY', 'NEAR OCEAN'], dtype=object)]
```

`fit()` 또는 `fit_transform()` 실행 후 `categories_` 인스턴스 변수에 학습된 범주 정보 저장됨
