# ML 개요 (Part 2) 정리

## 1. ML 시스템 분류 기준 3가지

> **핵심:** 이 3가지 기준은 **상호 배타적이지 않으며** 조합해서 사용 가능하다!

| 기준                     | 분류                     |
| ---------------------- | ---------------------- |
| 기준 1: 사람의 지도/감독 여부     | 지도 / 비지도 / 준지도 / 강화 학습 |
| 기준 2: 실시간 점진적 학습 가능 여부 | 온라인 학습 vs 배치 학습        |
| 기준 3: 일반화 방식           | 사례 기반 vs 모델 기반 학습      |

> **스팸 필터 조합 예시:** 지도 학습 + 온라인 학습 + 모델 기반 학습

---

## 2. 기준 1 — 지도/감독 여부

### 🔵 지도 학습 (Supervised Learning)

**정의:** 훈련 데이터에 **레이블(label) = 정답**이 포함된 경우. 레이블을 타깃(target)이라고도 함.

대표 유형: **분류(Classification)** 와 **회귀(Regression)**

**분류 vs 회귀 비교:**

| 구분  | 분류 (Classification)  | 회귀 (Regression) |
| --- | -------------------- | --------------- |
| 출력  | 카테고리 (스팸/햄, cat/dog) | 수치값 (가격, 온도 등)  |
| 예시  | 스팸 필터, 이미지 분류        | 중고차 가격 예측       |

**회귀 예시 (중고차 가격 예측):**

- **훈련셋:** 중고차 특성(feature) = 주행거리, 연식, 브랜드 + 레이블 = 가격
- **학습 후:** 새 중고차의 특성이 주어지면 가격을 예측

---

### 🔴 비지도 학습 (Unsupervised Learning)

**정의:** **레이블 없이** 시스템이 스스로 학습

대표 유형 4가지:

**① 군집 (Clustering)**

- 유사한 특징을 가진 데이터끼리 자동으로 그룹화
- 예: 고객을 구매 이력 기반으로 전자제품/식료품/가구 관심 그룹으로 분류
- 알고리즘: K-means, DBSCAN, 계층 군집 분석
- ⚠️ 레이블 없음 → 어느 그룹인지 사전에 알 수 없음

**② 시각화 (Visualization)**

- 레이블 없는 고차원 데이터를 **2D/3D**로 표현
- 원본 데이터의 구조/특징을 최대한 보존하는 것이 핵심
- 예상치 못한 패턴 발견 가능

**③ 차원 축소 (Dimensionality Reduction)**

- 정보 손실을 최소화하면서 특성(feature) 수를 줄임
- 예: 자동차 "주행거리"와 "연식" → "마모 정도"라는 하나의 특성으로 합침
- 장점: 훈련 시간 단축, 저장공간 절약, 모델 성능 향상

**④ 연관 규칙 학습 (Association Rule Learning)**

- 대규모 데이터에서 **특성 간 흥미로운 관계** 발견
- 예: "바비큐 소스 + 감자를 사는 고객 → 스테이크도 구매" → 세 상품을 가까이 진열

---

#### ⭐ 이상 탐지 vs 특이치 탐지 (시험 단골 비교!)

| 구분     | 이상 탐지 (Anomaly Detection) | 특이치 탐지 (Novelty Detection)   |
| ------ | ------------------------- | ---------------------------- |
| 훈련 데이터 | 대부분 정상 (일부 이상 포함 가능)      | **완전히 clean한** 정상 데이터만       |
| 목적     | 드문/비정상 샘플 탐지              | 훈련 데이터와 **달라 보이는** 새 데이터 탐지  |
| 치와와 예시 | 드문 종으로 인식 → **이상치로 분류**   | 훈련셋에 치와와가 있었으므로 → **특이치 아님** |
| 활용     | 신용카드 부정사용, 제조 결함 탐지       | 완전히 새로운 패턴 탐지                |

---

### 🟡 준지도 학습 (Semi-supervised Learning)

**정의:** 훈련 데이터 중 **일부만 레이블**이 있는 경우

**왜 필요한가?** 레이블 작업은 시간과 비용이 많이 들어 레이블 없는 데이터가 훨씬 많음

**동작 방식:** 비지도 + 지도 학습 혼용

1. 클러스터링으로 유사한 샘플끼리 그룹화
2. 그룹 내 레이블된 샘플 기반으로 나머지 unlabeled 샘플에 레이블링
3. 모든 샘플에 레이블이 생기면 지도 학습 실행

**예시: Google Photos**

- 가족 사진 업로드 → 클러스터링으로 구성원 A/B/C 자동 구분
- 사용자가 이름(레이블) 한 번만 달아주면 → 모든 사진 인식 가능

---

### 🟢 강화 학습 (Reinforcement Learning)

**핵심 용어:**

|용어|설명|
|---|---|
|**에이전트 (Agent)**|학습/훈련 대상|
|**환경 (Environment)**|에이전트가 처한 상황|
|**행동 (Action)**|에이전트가 취하는 선택|
|**정책 (Policy)**|주어진 환경에서 어떤 행동을 해야 하는지 규정|
|**보상/벌점**|행동 결과에 따라 주어지는 피드백|

**동작 흐름:**

```
관찰(Observe) → 정책으로 행동 선택 → 행동 실행 → 보상/벌점 획득 → 정책 업데이트 → 반복
```

**목표:** 보상을 극대화하는 방향으로 정책을 계속 수정

**예시: AlphaGo**

- 수백만 건의 바둑 게임 데이터 학습 → AlphaGo끼리 자체 대국으로 추가 학습
- 실제 이세돌과 대국 시: 학습 기능 OFF, 기존 학습된 전략만 사용

## 3. 기준 2 — 온라인 학습 vs 배치 학습

|항목|온라인 학습 (Online)|배치 학습 (Batch)|
|---|---|---|
|학습 단위|샘플 1개씩 또는 mini-batch|전체 훈련셋|
|학습 방식|점진적(incremental), 실시간|오프라인에서 한 번|
|적합한 상황|빠른 변화, 제한된 컴퓨팅 자원|충분한 컴퓨팅 자원|
|새 데이터 적응|즉시 학습 가능|전체 데이터 포함하여 **재훈련** 필요|
|단점|나쁜 데이터 유입 시 성능 저하 → 모니터링 필수|대용량 시간/자원 소모|
|예시|주식 가격 예측, 모바일 기기|정기적 재훈련 모델|

> **온라인 학습의 특이한 활용:** 메모리에 올릴 수 없는 방대한 데이터를 조각내서 순차 학습하는 **외부 메모리 학습(out-of-core learning)**

---

## 4. 기준 3 — 사례 기반 vs 모델 기반 학습

> **일반화(Generalization):** 새로운 데이터에 대해 예측하는 것

| 항목      | 사례 기반 (Instance-based)         | 모델 기반 (Model-based)          |
| ------- | ------------------------------ | ---------------------------- |
| 학습 과정   | 훈련 샘플을 **통째로 기억**              | 훈련셋으로 모델 파라미터를 학습            |
| 예측 방식   | 새 샘플과 기존 샘플의 **유사도** 측정        | 학습된 모델로 예측                   |
| 대표 알고리즘 | **k-NN** (k-nearest neighbors) | 선형 회귀, SVM, Neural Network 등 |
| 특징      | 별도의 모델 파라미터 없음                 | θ0, θ1 같은 파라미터 최적화           |

**모델 기반 학습 예시 (선형 회귀):**

```
life_satisfaction = θ0 + θ1 × GDP_per_capita
```

- 훈련 과정: θ0, θ1을 조정하며 훈련 데이터에 가장 잘 맞는 값 탐색 반복
- 최적값 예: θ0 = 3.75, θ1 = 6.78×10⁻⁵

## 5. ML의 주요 도전 과제

### 📌 데이터 관련 문제

**① 훈련 데이터 부족**

- 간단한 문제도 수천 개 이상 필요
- 이미지 분류, 음성 인식 → 수백만 개 필요할 수도 있음
- 일반적으로 **데이터가 많을수록 성능이 좋아짐**

**② 대표성 없는 훈련 데이터**

- **샘플링 노이즈:** 우연히 추가된 대표성 없는 데이터
- **샘플링 편향:** 표본 추출 방법이 잘못되어 편향된 데이터
- 어떤 데이터를 사용하냐가 모델에 큰 영향을 미침

**③ 저품질 데이터**

- 이상치, 노이즈가 많은 데이터로는 좋은 모델 불가
- **"Garbage in, garbage out"** ← 반드시 암기!
- 해결책: 이상치 보정/제거, 결측치는 평균값으로 채우거나 샘플 제외

**④ 특성 공학 (Feature Engineering)**

- 문제 해결에 관련성 높은 특성을 찾는 것이 중요
- **특성 선택(Feature selection):** 유용한 특성을 골라냄
- **특성 추출(Feature extraction):** 상관관계 높은 특성들을 합쳐 새 특성 생성 (예: 주행거리 + 연식 → "마모 정도")

---

### 📌 알고리즘 관련 문제

**① 과대 적합 (Overfitting)** ⭐

훈련셋에 너무 딱 맞아서 **새로운 샘플에 대한 일반화 성능이 떨어지는** 현상

- 훈련 오차 < 일반화 오차 → 과대 적합 신호
- 해결책: **규제(Regularization)** 적용
    - 훈련 중 모델이 데이터에 덜 민감하게 반응하도록 강제
    - 규제 적용 시 훈련 데이터 패턴 반영은 줄지만, 새 샘플에 대한 일반화 성능은 높아짐

**② 과소 적합 (Underfitting)**

모델이 너무 단순해서 **훈련 데이터의 패턴조차 제대로 못 잡는** 현상

- 해결책:
    - 더 복잡한 모델(파라미터 더 많은)로 교체
    - 더 좋은 특성 활용
    - 규제 완화

|비교|과대 적합|과소 적합|
|---|---|---|
|원인|모델이 너무 복잡|모델이 너무 단순|
|훈련 오차|낮음|높음|
|일반화 오차|높음|높음|
|해결책|규제 추가, 데이터 늘리기|더 복잡한 모델, 규제 완화|

## 6. 테스트와 검증

### 데이터셋 분할

```
전체 Dataset
├── Training set (80%)
│   ├── Training set (실제 훈련용)
│   └── Validation set (모델 선택/튜닝용)
└── Test set (20%) ← 최종 성능 평가만!
```

### 핵심 용어

|용어|설명|
|---|---|
|**훈련 오차**|훈련 샘플에 대해 예측이 틀리는 비율|
|**일반화 오차**|새로운(미지의) 샘플에 대해 예측이 틀리는 비율|
|**하이퍼파라미터**|모델 훈련 과정에 관한 학습 알고리즘의 파라미터 (예: 규제의 강도)|

> 훈련 오차 << 일반화 오차 → **과대 적합!**

---

### 홀드아웃 검증 (Holdout Validation)

훈련셋의 일부를 **검증셋(validation set)** 으로 따로 빼서 여러 후보 모델들의 성능을 비교하는 방법. 하이퍼파라미터 튜닝 시 최적 설정값을 찾는 데 사용.

---

### 교차 검증 (Cross Validation) ⭐

훈련셋을 **k개의 fold**로 나눠서 검증하는 방법

**동작 방식 (k=5 예시):**

1. 훈련셋을 5개 fold로 분할
2. Fold 1을 검증셋으로, 나머지 4개를 훈련셋으로 사용 → 성능 평가
3. Fold 2, 3, 4, 5를 각각 검증셋으로 반복
4. **5번의 성능 평가 평균** → 최종 검증 결과

|항목|내용|
|---|---|
|장점|검증셋 하나만 쓰는 것보다 **훨씬 정확한 성능 평가**|
|단점|k가 커질수록 훈련 **시간/비용 증가**|

---

### 중요 용어 정리

**모델(Model)의 3가지 의미:**

- 모델의 종류 (e.g., linear regression, SVM)
- 완전히 정의된 모델 구조 (e.g., 입력 1개, 출력 1개인 linear regression)
- 훈련된 최종 모델 (e.g., θ0=3.75, θ1=6.78×10⁻⁵인 모델)

**모델 vs 학습 알고리즘:**

- **모델:** 훈련시키고자 하는 **대상**
- **학습 알고리즘:** 모델을 훈련시키는 **방법/절차**
