# 머신러닝 프로젝트 처음부터 끝까지 (Part 1) 정리

명지대학교 강의자료 기반으로 정리했어. 시험에 나올 만한 핵심 개념 위주로 최대한 자세하게 썼어.

## 개요 - 이 프로젝트의 목표

캘리포니아 주 20,640개 구역(district)의 인구조사 데이터를 이용해서 **중간 주택 가격(median_house_value)을 예측하는 회귀 모델**을 만드는 것이 목표야.

전체 흐름은 이렇게 8단계로 구성돼:

> 큰 그림 보기 → 데이터 구하기 → 탐색 및 시각화 → 데이터 준비 → 모델 선택 및 훈련 → 모델 튜닝 → 솔루션 제시 → 시스템 론칭 및 유지보수

### 문제 정의 (시험 포인트!)

이 문제가 어떤 ML 범주에 속하는지 정확히 분류할 수 있어야 해.

**① 지도 학습(Supervised Learning)**

- 레이블(타깃)이 존재하기 때문 → 구역별 중간 주택 가격

**② 회귀(Regression)**

- 연속적인 수치값(주택 가격)을 예측하는 문제이기 때문
- 분류(Classification)가 아님 — 분류는 카테고리를 예측하는 것

더 구체적으로 분류하면:

| 종류                                 | 이유                      |
| ---------------------------------- | ----------------------- |
| **다중 회귀 (Multiple Regression)**    | 입력 특성이 9개(여러 개)이기 때문    |
| **단변량 회귀 (Univariate Regression)** | 예측하는 출력값이 주택 가격 하나이기 때문 |

> **참고 — 다변량 회귀(Multivariate Regression)**: 예측 출력값이 여러 개일 때를 말함. 이 프로젝트는 해당 없음.

**③ 배치 학습(Batch Learning)**

- 데이터가 빠르게 변하지 않고, 크기도 작은 편
- 주어진 데이터셋 전체를 오프라인에서 한 번에 훈련
- 온라인 학습(Online Learning)은 실시간으로 조금씩 업데이트하는 방식 — 이 프로젝트는 해당 없음

### 성능 평가 지표

선형 회귀 모델의 성능 평가에는 두 가지 지표를 주로 사용해.

#### RMSE (Root Mean Square Error, 평균 제곱근 오차)

RMSE(X,h)=1m∑i=1m(h(x(i))−y(i))2\text{RMSE}(\mathbf{X}, h) = \sqrt{\frac{1}{m}\sum_{i=1}^{m}\left(h(\mathbf{x}^{(i)}) - y^{(i)}\right)^2}RMSE(X,h)=m1​i=1∑m​(h(x(i))−y(i))2​

**수식 표기법 완벽 정리:**

|기호|의미|예시|
|---|---|---|
|m|데이터셋의 총 샘플 수|2,000개 구역 → m=2000|
|**x**(i)|i번째 샘플의 입력 특성 벡터 (타깃 제외)|column vector로 표기|
|y(i)|i번째 샘플의 타깃값|y(1) = 156,400|
|h(**x**(i)) = ŷ(i)|모델의 i번째 샘플 예측값|ŷ(1) = 158,400|
|**X**|전체 데이터셋 matrix (각 행 = 샘플 하나)|uppercase bold|
|h|예측 함수 (hypothesis)|선형회귀 모델 등|

- prediction error = ŷ(i) - y(i) → 예: 158,400 - 156,400 = 2,000
- **x**(i)는 **lowercase bold**, **X**는 **uppercase bold**로 표기하는 것이 규칙

**RMSE 특징:**

- Euclidean norm (ℓ₂ norm) 이라고도 불림
- 오차가 큰 샘플이 있으면 RMSE에 큰 영향을 미침
- **이상치(outlier)에 민감함** → 이상치가 많으면 RMSE가 부풀려짐

#### MAE (Mean Absolute Error, 평균 절대 오차)

MAE(X,h)=1m∑i=1m∣h(x(i))−y(i)∣\text{MAE}(\mathbf{X}, h) = \frac{1}{m}\sum_{i=1}^{m}\left|h(\mathbf{x}^{(i)}) - y^{(i)}\right|MAE(X,h)=m1​i=1∑m​​h(x(i))−y(i)​

- Manhattan norm (ℓ₁ norm) 이라고도 불림
- **이상치가 많은 경우 RMSE보다 적합**
- 하지만 이상치가 많지 않을 경우에는 일반적으로 **RMSE를 사용**

> **RMSE vs MAE 비교 요약:** RMSE는 오차를 제곱하기 때문에 큰 오차에 더 민감하고, MAE는 절댓값을 쓰기 때문에 이상치 영향이 상대적으로 작아.

### 테스트셋 만들기

**왜 미리 테스트셋을 분리해야 할까?**

- 테스트셋을 미리 보면 **data snooping 편향** 발생 위험
- 테스트셋 정보가 무의식적으로 모델 선택에 영향을 줘서 **일반화 성능이 떨어지는 모델**이 될 수 있음
- 비율: 훈련셋 약 80%, 테스트셋 약 20%

**두 가지 샘플링 방식 비교:**

|방식|설명|단점|
|---|---|---|
|무작위 샘플링 (Random Sampling)|랜덤으로 추출|모집단의 계층 비율이 테스트셋에 제대로 반영 안 될 수 있음|
|**계층적 샘플링 (Stratified Sampling)**|계층별 비율 유지하며 추출|없음 (이 프로젝트에서 사용)|

**계층적 샘플링이란?**

- 계층(strata) = 동질 그룹 (예: 남성/여성, 소득 구간)
- 전체 모집단의 계층 비율이 테스트셋에도 최대한 반영되도록 각 계층에서 적절히 샘플 추출
- 특정 계층이 너무 적거나 많으면 해당 계층의 중요도가 과소/과대 평가됨

**이 프로젝트에서의 계층 기준 → median_income(중간 소득)**

- 중간 소득이 주택 가격 예측에 가장 중요한 특성이라고 판단했기 때문
- 5개 소득 구간 계층으로 나눔:

|계층|소득 범위|
|---|---|
|계층 1|0 ~ 1.5|
|계층 2|1.5 ~ 3.0|
|계층 3|3.0 ~ 4.5|
|계층 4|4.5 ~ 6.0|
|계층 5|6.0 이상|

**결과 비교:** 계층적 샘플링은 전체 모집단 비율과의 오차가 최대 0.36% 수준인 반면, 무작위 샘플링은 최대 6.45%까지 오차가 발생함 → **계층적 샘플링이 훨씬 대표성이 높은 테스트셋을 만들어냄**

## 3. 데이터 탐색 및 시각화

> **주의:** Data snooping 편향 방지를 위해 **훈련셋에 대해서만** 탐색 및 시각화 수행!

### 지리적 데이터 시각화

- 위도/경도로 산점도를 그리면 샘플 밀집 지역 확인 가능
- **샌프란시스코 Bay area, LA, 샌디에고** 지역에 샘플 밀집
- 색상(주택 가격)과 점 크기(인구)를 함께 표현한 시각화 결과:
    - **해안에 근접하고 인구 밀도가 높은 지역일수록 주택 가격이 높은 경향**
    - 단, 북부 캘리포니아 해안가는 예외적으로 주택 가격이 낮음

### 특성 간 상관관계

**상관계수(Correlation Coefficient) 특징:**

|값|의미|
|---|---|
|1에 근접|강한 양의 선형 상관관계 (x↑ → y↑)|
|-1에 근접|강한 음의 선형 상관관계 (x↑ → y↓)|
|0에 근접|선형적 상관관계 없음|

**주의사항 (시험 포인트!):**

- 상관계수는 **선형적 관계만** 측정함
- 상관계수가 0이어도 비선형적 관계는 존재할 수 있음
- **상관계수와 기울기는 무관** (기울기가 달라도 상관계수는 같을 수 있음)

**median_house_value와 각 특성 간 상관계수 결과:**

- `median_income`: **0.69** → 가장 높은 양의 상관관계
- `total_rooms`: 0.14
- `housing_median_age`: 0.10
- `latitude`: -0.14 (음의 관계)

**산점도에서 발견된 이상 패턴:**

- $500,000 수평선: 주택 가격 상한이 제한된 것으로 보임
- $450,000, $350,000, $280,000 근처에도 수평선 존재
- 이런 이상 패턴을 학습하지 않도록 해당 구역을 데이터셋에서 **제거하는 것이 바람직**

### 특성 조합으로 새 특성 만들기

기존 특성을 조합해서 더 유용한 새 특성을 만들 수 있어:

|새 특성|계산 방법|median_house_value와 상관계수|
|---|---|---|
|rooms_per_house|total_rooms / households|0.14|
|bedrooms_ratio|total_bedrooms / total_rooms|**-0.26** (꽤 높음)|
|people_per_house|population / households|-0.04|

- **bedrooms_ratio**가 기존의 total_bedrooms(-0.05)보다 중간 주택 가격과 훨씬 강한 상관관계를 가짐
- 침실 비율이 낮은 집(방 대비 침실이 적은, 즉 거실 등이 많은 집)이 더 비싼 경향
