# 📌 트랜잭션 상태(Transaction State) 완벽 이해하기

트랜잭션은 실행되는 동안 여러 상태를 거쳐서  
**시작 → 실행 → 커밋 or 롤백 → 종료**  
라는 전체 흐름을 가진다.

아래는 이 과정을 시각적으로 표현한 일반적인 상태 전이도야:

`Active → Partially Committed → Committed       
	↘         Failed → Aborted`

이제 각 상태를 직관적으로 하나씩 설명해볼게.

---

# 1️⃣ Active (활동 상태)

### ✔ 정의

트랜잭션이 **시작되어 연산을 실행 중인 상태**.

### ✔ 특징

- read, write 같은 기본 작업을 수행 중
    
- 아직 모든 연산을 마치지 않았기 때문에 실패 가능성이 있음
    

### ✔ 예시

A → B 로 50달러 이체할 때:

`read(A) A = A - 50 write(A)`

이런 단계들을 실행하는 중이면 아직 Active 상태.

---

# 2️⃣ Partially Committed (부분 커밋 상태)

### ✔ 정의

트랜잭션의 논리적 작업을 **모두 정상적으로 끝낸 상태**  
(마지막 명령까지 오류 없이 실행됨)

하지만! 아직 디스크에 영구 저장되진 않았음.

### ✔ 특징

- “이제 거의 끝남”
    
- 하지만 아직 진짜 커밋 아님
    
- 시스템이 여기서 다운되면 롤백될 수도 있음
    

### ✔ 예시

`모든 SQL 실행 완료 → 하지만 DB 버퍼에만 기록되어 있고 디스크에는 아직 반영 안 됨`

---

# 3️⃣ Failed (실패 상태)

### ✔ 정의

트랜잭션이 도중에 **더 이상 정상적으로 진행될 수 없다고 판단된 상태**.

### ✔ 발생 원인

- 제약 조건 위반 (예: 잔액이 음수가 됨)
    
- deadlock
    
- 디스크 오류
    
- 프로그램 오류
    
- 시스템 장애 등
    

### ✔ 특징

- 거래는 더 이상 진행 불가
    
- 롤백 준비 단계
    

---

# 4️⃣ Aborted (철회/취소 상태)

### ✔ 정의

실패한 트랜잭션에 대해 **모든 변경 사항을 롤백해 원래 상태로 되돌린 상태**.

### ✔ 발생 흐름

`Failed → Aborted`

### ✔ 특징

- 데이터는 트랜잭션 시작 전의 상태로 완전히 복구됨
    
- 트랜잭션은 종료됨
    

### ✔ 두 가지 선택

1. **재시작(Restart)**  
    일시적 문제라면 처음부터 다시 실행 가능  
    (예: deadlock으로 인해 실패했을 때)
    
2. **완전 종료(Kill)**  
    논리적 오류라면 재실행해도 실패하므로 트랜잭션을 아예 종료
    

---

# 5️⃣ Committed (커밋 상태)

### ✔ 정의

트랜잭션이 **성공적으로 완료되고**,  
그 결과가 **디스크에 영구 저장된 상태**.

### ✔ 특징

- 이제 시스템이 꺼져도 결과는 절대 사라지지 않음
    
- ACID의 “지속성(Durability)”을 충족
    

### ✔ 예시

A에서 50 빠지고 B에 50 들어가는 작업이 완전히 반영되어  
이제 은행 계좌 DB에 영구 저장된 상태.

---

# 📌 전체 흐름 요약 표

|상태|의미|핵심 포인트|
|---|---|---|
|**Active**|트랜잭션 실행 중|read/write를 수행|
|**Partially Committed**|모든 명령 실행 완료|아직 디스크에 기록되진 않음|
|**Failed**|더 이상 진행 불가|제약 위반 또는 시스템 오류|
|**Aborted**|롤백 완료|원래 상태로 되돌림, 종료 or 재시작|
|**Committed**|실행 성공, 디스크 반영|결과가 영구 저장됨|

---

# 📌 이해를 돕는 비유 — “택배 주문 과정”

트랜잭션을 **온라인 쇼핑 주문**이라고 생각해보자.

|DB 상태|비유|
|---|---|
|Active|상품 고르는 중 & 결제 진행 중|
|Partially Committed|결제 완료 → 주문 접수 되었지만 아직 배송 출발 전|
|Failed|결제 실패, 품절, 시스템 오류 발생|
|Aborted|주문 취소 처리 완료 (결제 취소 & 상태 복구)|
|Committed|배송 출발 → 취소 불가, 결과 확정|
