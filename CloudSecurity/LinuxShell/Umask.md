# umask 완전 정리

## 먼저, 권한 숫자가 뭔지부터

리눅스 권한은 **r(읽기)=4, w(쓰기)=2, x(실행)=1** 로 구성됩니다.

```
rwx = 4+2+1 = 7
rw- = 4+2+0 = 6
r-- = 4+0+0 = 4
```

그리고 권한은 **소유자 / 그룹 / 기타** 3자리로 표현해요.

```
777 = rwx rwx rwx  (모두 다 가능)
666 = rw- rw- rw-  (실행만 빼고 다 가능)
```

---

## 왜 파일 최고 권한이 666일까?

**파일은 기본적으로 실행(x)이 필요 없기 때문이에요.**

- 일반 텍스트 파일, 사진, 문서 등은 실행할 일이 없음
- 그래서 처음부터 실행 권한을 빼고 시작 → `rw- rw- rw-` = **666**

반면 **디렉토리는 실행(x)이 필수**예요.

- 디렉토리에서 x는 "이 폴더 안에 들어갈 수 있다"는 의미
- x가 없으면 `cd`도 못하고 파일 목록도 못 봄
- 그래서 최고 권한이 `rwx rwx rwx` = **777**

---

## umask가 하는 일

umask는 **"이 권한 비트는 꺼주세요"** 라는 마스크예요.

umask가 `0002`라면 → **마지막 기타 사용자의 w(쓰기)를 꺼라**는 뜻

```
  666  (파일 최고 권한)
- 002  (umask)
─────
  664  → rw-rw-r--
```

```
  777  (디렉토리 최고 권한)
- 002  (umask)
─────
  775  → rwxrwxr-x
```

---

## 실제 결과와 비교

```
-rw-rw-r--  c.txt       → 664 ✅
drwxrwxr-x  test_dir    → 775 ✅
```

---

## 전체 흐름 정리

```
파일 생성 시:   666 (최고) - 002 (umask) = 664 (rw-rw-r--)
디렉토리 생성:  777 (최고) - 002 (umask) = 775 (rwxrwxr-x)
```

|최고 권한|umask|실제 권한|
|---|---|---|---|
|파일|666|002|664|
|디렉토리|777|002|775|

> **핵심 한 줄 요약:** umask는 "새로 만드는 파일/폴더에서 기본으로 제거할 권한"이고, 파일은 실행 권한이 처음부터 없어서 최고가 666, 디렉토리는 실행이 필수라 777에서 시작합니다.
