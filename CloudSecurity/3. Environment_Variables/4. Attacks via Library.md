### 1. Attacks via Library (라이브러리를 통한 공격)

#### 개념

프로그램이 외부 라이브러리 함수를 쓸 때, 그 **라이브러리 함수가 환경변수를 참조**하면 공격 표면이 생깁니다.

---

#### Case Study: UNIX Locale (다국어 처리)

프로그램이 메시지를 출력할 때 언어에 맞게 번역하는 기능입니다.

c

```c
printf(gettext("usage: %s filename"), argv[0]);
//      ↑
//  번역된 문자열을 가져오는 함수
```

`gettext()`, `catopen()` 함수가 내부적으로 이런 환경변수를 참조합니다:

```
LANG, LANGUAGE, NLSPATH, LOCPATH, LC_ALL, LC_MESSAGES
```

**문제:** 이 변수들을 사용자가 마음대로 설정 가능 → 번역 메시지 조작 가능 → **Format String 취약점** 공격으로 연결될 수 있음

#### 대응책

라이브러리 개발자가 책임져야 합니다. 예를 들어 Glibc 2.1.1은 Set-UID 프로그램에서 `catopen()`, `catgets()` 호출 시 **NLSPATH를 자동으로 무시**합니다.
