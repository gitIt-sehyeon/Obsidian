### 2. Attacks via Application Code (앱 코드를 통한 공격)

#### 취약한 코드 예시

c

```c
char arr[64];           // 64바이트 고정 배열
char *ptr;

ptr = getenv("PWD");    // PWD 환경변수 읽기
if(ptr != NULL) {
    sprintf(arr, "Present working directory is: %s", ptr);
    //            ↑ 길이 체크 없음! → Buffer Overflow 가능
    printf("%s\n", arr);
}
```

**문제 2가지:**

**① Buffer Overflow**

```
arr 크기 = 64바이트
PWD 값이 64바이트보다 길면? → 버퍼 오버플로우!
```

**② PWD 값을 사용자가 조작 가능**

bash

```bash
$ pwd
/home/seed/temp       # 실제 경로

$ PWD=xyz             # 사용자가 PWD를 임의로 변경!
$ echo $PWD
xyz                   # 실제 경로와 달라짐

$ pwd                 # 실제 경로는 여전히 /
/
```

→ `getenv("PWD")`는 **실제 경로가 아니라 환경변수 값**을 가져오므로 조작 가능!

#### 대응책: `secure_getenv()` 사용

|함수|동작|
|---|---|
|`getenv()`|항상 환경변수 값 반환|
|`secure_getenv()`|EUID ≠ RUID (Set-UID 실행 중)이면 **NULL 반환**|

c

```c
ptr = secure_getenv("PWD");  // Set-UID 프로그램에서 안전하게 사용
if(ptr != NULL) { ... }      // NULL이면 그냥 건너뜀
```

**Set-UID 프로그램에서는 환경변수를 신뢰하면 안 되므로** `secure_getenv()`를 써야 합니다.
