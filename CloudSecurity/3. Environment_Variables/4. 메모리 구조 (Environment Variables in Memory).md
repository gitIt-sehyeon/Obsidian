# 4. 메모리 구조 (Environment Variables in Memory)

---

## 4.1 개요

환경변수는 단순한 문자열 집합이 아니라  
**프로세스 메모리 구조 안에서 특정 방식으로 저장된다**

이 구조를 이해하면:

- envp가 왜 포인터 배열인지
    
- environ이 왜 바뀌는지
    
- getenv가 어떻게 동작하는지
    

전부 연결된다.

---

## 4.2 환경변수 초기 저장 위치

프로세스가 시작될 때:

```text
환경변수는 stack 영역에 저장된다
```

---

## 4.3 전체 메모리 구조 (PDF 핵심 그림 해석)

프로그램 시작 직전 스택에는 다음 4가지가 들어간다:

```text
[ stack ]

(1) 환경변수 문자열 영역
(2) envp (환경변수 포인터 배열)
(3) argv (인자 포인터 배열)
(4) main 함수의 stack frame
```

---

## 4.4 구조 상세 설명

### (1) 환경변수 문자열 영역

```text
"PATH=/usr/bin"
"HOME=/home/user"
"LANG=en_US"
```

- 실제 데이터가 저장되는 공간
    
- 문자열 형태로 연속 저장됨
    

---

### (2) envp 배열

```c
char *envp[] = {
    "PATH=/usr/bin",
    "HOME=/home/user",
    "LANG=en_US",
    NULL
};
```

- 문자열을 직접 저장하지 않음
    
- 문자열을 가리키는 포인터 배열
    

---

### (3) argv 배열

```c
char *argv[] = {
    "program",
    "arg1",
    "arg2",
    NULL
};
```

- 프로그램 실행 인자
    
- envp와 동일한 구조
    

---

### (4) main stack frame

- main 함수 실행을 위한 스택 영역
    
- 지역 변수, return address 포함
    

---

## 4.5 구조 관계 요약

```text
envp → 문자열 영역을 가리킴
argv → 문자열 영역을 가리킴

모든 실제 데이터는 문자열 영역에 존재
```

---

## 4.6 NULL 종료 구조 (중요)

envp와 argv는 모두:

```text
NULL 포인터로 끝난다
```

예:

```c
envp[i] != NULL
```

---

## 4.7 envp vs environ 관계 (PDF 핵심)

초기 상태에서는:

```text
envp == environ
```

즉:

- 둘 다 같은 메모리 위치를 가리킴
    

---

## 4.8 환경변수 변경 시 발생하는 변화 (중요)

환경변수가 변경되면:

```text
stack → heap으로 이동할 수 있다
```

---

### 이유

- 새로운 환경변수 추가
    
- 기존 공간 부족
    

---

### 결과

```text
envp     → 기존 stack 위치 유지
environ  → 새로운 heap 위치 가리킴
```

---

## 4.9 핵심 차이

|항목|envp|environ|
|---|---|---|
|위치|초기 stack|변경 시 heap 이동|
|값 반영|안 됨|반영됨|

---

## 4.10 동작 흐름

```text
프로그램 시작
   ↓
stack에 envp + 문자열 저장
   ↓
envp == environ
   ↓
환경변수 변경 발생
   ↓
heap으로 이동
   ↓
environ만 새 위치 가리킴
```

---

## 4.11 getenv() 내부 동작 (연결 개념)

```c
char *getenv(const char *name);
```

동작 방식:

```text
environ 배열을 순회하면서
"KEY=VALUE" 문자열 검색
```

---

## 4.12 코드로 구조 확인 (실습용)

```c
#include <stdio.h>

extern char **environ;

int main(int argc, char *argv[], char *envp[]) {
    printf("envp[0]: %p\n", envp[0]);
    printf("environ[0]: %p\n", environ[0]);
}
```

---

## 4.13 핵심 요약

```text
환경변수는 stack에 문자열 형태로 저장된다

envp, argv는 포인터 배열이다

envp와 environ은 처음에는 동일하다

환경변수가 변경되면 environ만 새로운 위치를 가리킨다
```

---

## 4.14 한 줄 정리

환경변수는 문자열 데이터 + 포인터 배열 구조로 메모리에 저장된다
