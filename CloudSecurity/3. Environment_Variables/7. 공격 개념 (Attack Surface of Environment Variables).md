# 7. 공격 개념 (Attack Surface of Environment Variables)

---

## 7.1 개요

환경변수는 단순한 설정값이 아니라  
**프로그램 동작에 직접 영향을 주는 입력 데이터**이다.

---

## 7.2 핵심 개념

```text
환경변수는 사용자에 의해 설정될 수 있다
```

즉:

```text
신뢰할 수 없는 입력(untrusted input)
```

---

## 7.3 Attack Surface (공격 표면)

### 정의

```text
Attack Surface = 공격자가 영향을 줄 수 있는 입력 지점
```

---

### 환경변수의 위치

```text
환경변수 → 프로세스 실행 전에 주입됨
```

---

### 의미

- 프로그램 실행 전부터 영향 가능
    
- 코드 내부 검증 이전에 개입 가능
    

---

## 7.4 PDF 핵심 문장 해석

```text
Hidden usage of environment variables is dangerous
```

---

### 해석

- 개발자가 인지하지 못한 환경변수 사용이 존재할 수 있음
    
- 라이브러리, 시스템 호출 내부에서도 사용됨
    

---

### 결과

```text
의도하지 않은 동작 발생 가능
```

---

## 7.5 환경변수가 위험한 이유

### 1. 외부 입력 가능

```bash
export PATH=...
export LD_PRELOAD=...
```

- 사용자가 자유롭게 설정 가능
    

---

### 2. 프로그램 동작 변경 가능

예:

```text
PATH → 실행 파일 변경
LD_PRELOAD → 함수 동작 변경
```

---

### 3. 실행 흐름 개입 가능

- 프로그램 실행 이전 단계에서 영향
    
- 런타임 동작 조작 가능
    

---

## 7.6 Set-UID 프로그램과의 결합 (핵심 위험)

### 개념

Set-UID 프로그램:

```text
일반 사용자가 root 권한으로 실행하는 프로그램
```

---

### 문제

```text
환경변수는 일반 사용자가 설정 가능
하지만 프로그램은 root 권한으로 실행됨
```

---

### 결과

```text
권한 상승 공격 가능
```

---

## 7.7 공격 흐름

```text
1. 공격자가 환경변수 설정
2. 프로그램 실행
3. 환경변수 기반 동작 변경
4. 의도하지 않은 코드 실행
```

---

## 7.8 환경변수 사용 위치 (PDF 암시 내용)

환경변수는 다양한 곳에서 사용된다:

```text
- dynamic linker
- shell
- external program 실행
- 라이브러리 내부
- application 코드
```

---

## 7.9 핵심 문제

```text
개발자는 환경변수를 직접 사용하지 않아도
시스템 내부에서 사용될 수 있다
```

---

### 의미

- 숨겨진 공격 경로 존재
    
- 예상 못한 취약점 발생
    

---

## 7.10 보안 관점 핵심

```text
환경변수는 입력값이다
```

---

### 따라서

```text
검증 없이 사용하면 취약점 발생
```

---

## 7.11 전체 구조 연결

```text
환경변수
  ↓
프로세스 전달 (fork/exec)
  ↓
라이브러리 / 시스템 호출 사용
  ↓
공격 가능
```

---

## 7.12 핵심 요약

```text
환경변수는 사용자 입력이다

프로그램 실행 전부터 영향을 준다

숨겨진 사용이 많다

Set-UID와 결합 시 매우 위험하다
```

---
