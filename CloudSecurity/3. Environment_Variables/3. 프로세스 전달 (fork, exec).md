# 3. 프로세스 전달 (fork, exec)

---

## 3.1 개요

프로세스가 환경변수를 가지는 방식은 두 가지이다.

```text
1. fork() → 부모로부터 환경변수 상속
2. execve() → 새로운 프로그램 실행 시 환경변수 전달
```

이 두 시스템 호출이 리눅스 프로세스 모델의 핵심이다.

---

## 3.2 fork() - 환경변수 상속

### 개념

```c
pid_t pid = fork();
```

- 부모 프로세스를 복사하여 자식 프로세스를 생성
    
- 주소 공간을 포함한 모든 상태가 복사됨
    

---

### 환경변수 동작

- 자식 프로세스는 부모의 환경변수를 그대로 상속
    
- envp, environ 모두 동일한 값을 가짐
    

---

### 특징

- 별도의 전달 과정 없음
    
- 복사 기반(inherit)
    

---

### 결과

```text
부모 환경변수 = 자식 환경변수
```

---

## 3.3 execve() - 환경변수 전달

### 개념

```c
int execve(const char *filename, char *const argv[], char *const envp[]);
```

- 현재 프로세스를 새로운 프로그램으로 완전히 교체
    
- 기존 코드, 데이터, 스택 모두 제거됨
    

---

### 환경변수 동작

- 기존 환경변수는 유지되지 않음
    
- 새로운 환경변수는 envp를 통해 전달
    

---

### 핵심 특징

```text
기존 환경 → 제거
새 환경 → envp로 설정
```

---

### envp 구조

```c
char *envp[] = {
    "AAA=aaa",
    "BBB=bbb",
    NULL
};
```

- 문자열 배열
    
- 마지막은 NULL
    

---

## 3.4 execve 환경변수 전달 방식 비교 (PDF 핵심 예제)

다음은 execve 동작을 비교하는 대표적인 코드 구조이다.

```c
extern char **environ;

char *v[2];
char *newenv[3];

v[0] = "/usr/bin/env";
v[1] = NULL;

newenv[0] = "AAA=aaa";
newenv[1] = "BBB=bbb";
newenv[2] = NULL;

switch(argv[1][0]) {
    case '1':
        execve(v[0], v, NULL);
    case '2':
        execve(v[0], v, newenv);
    case '3':
        execve(v[0], v, environ);
}
```

---

### case 1: envp = NULL

```c
execve(..., NULL);
```

- 환경변수 없음
    
- 실행된 프로그램은 빈 환경에서 시작
    

---

### case 2: envp = newenv

```c
execve(..., newenv);
```

- 새로운 환경변수만 전달
    
- 기존 환경변수는 사라짐
    

결과 예시:

```text
AAA=aaa
BBB=bbb
```

---

### case 3: envp = environ

```c
execve(..., environ);
```

- 기존 환경변수 그대로 전달
    
- 부모 환경 유지
    

---

### /usr/bin/env를 사용하는 이유

```text
env 프로그램은 현재 프로세스의 환경변수를 출력한다
```

- execve 결과를 확인하기 위한 도구
    
- 전달된 envp 내용을 직접 눈으로 확인 가능
    

---

## 3.5 fork + exec 패턴 (중요)

실제 리눅스에서 프로그램 실행은 보통 다음 구조를 따른다.

```c
pid_t pid = fork();

if (pid == 0) {
    execve("/bin/ls", argv, environ);
}
```

---

### 흐름

1. fork() 호출 → 자식 생성
    
2. 자식에서 execve() 호출 → 새로운 프로그램 실행
    

---

### 환경변수 흐름

```text
부모 env
   ↓ (fork)
자식 env (복사)
   ↓ (execve)
새 env (envp에 따라 결정)
```

---

## 3.6 핵심 비교 정리

|구분|fork|execve|
|---|---|---|
|역할|프로세스 복사|프로그램 교체|
|환경변수|자동 상속|직접 전달|
|메모리|유지|완전 교체|

---

## 3.7 핵심 요약

```text
fork
- 부모 환경변수 그대로 복사

execve
- 기존 환경 제거
- envp로 새로운 환경 설정
```

---

## 3.8 한 줄 정리

fork는 환경을 복사하고, execve는 환경을 재구성한다
