# 2. 환경변수 접근 방법 (envp, environ)

---

##  개요

환경변수는 프로세스 내부에서 접근해야 의미가 있다.  
C 프로그램에서는 크게 **두 가지 방법**으로 접근할 수 있다:

```text
1. main 함수의 envp 파라미터
2. 전역 변수 environ
```

---

##  방법 1: main 함수의 envp

##  함수 시그니처

```c
int main(int argc, char *argv[], char *envp[])
```

---

##  구조

- `envp`는 **환경변수 배열**
    
- 각 요소는 `"KEY=VALUE"` 형태 문자열
    
- 마지막은 `NULL`
    

```text
envp
 ├── "PATH=/usr/bin"
 ├── "HOME=/home/user"
 ├── ...
 └── NULL
```

---

##  사용 예시

```c
#include <stdio.h>

int main(int argc, char *argv[], char *envp[]) {
    int i = 0;

    while (envp[i] != NULL) {
        printf("%s\n", envp[i]);
        i++;
    }
}
```

---

##  특징

- main 함수 내부에서만 사용 가능
    
- 초기 환경변수 상태를 그대로 반영
    

---

##  PDF 핵심 포인트

> envp는 환경변수 문자열을 가리키는 포인터 배열이다

---

#  방법 2: 전역 변수 environ (더 중요)

---

##  선언

```c
extern char **environ;
```

---

##  구조

- `envp`와 동일한 구조
    
- 전역 변수이기 때문에 어디서든 접근 가능
    

---

##  사용 예시

```c
#include <stdio.h>

extern char **environ;

int main() {
    int i = 0;

    while (environ[i] != NULL) {
        printf("%s\n", environ[i]);
        i++;
    }
}
```

---

##  특징

- 프로그램 전체에서 접근 가능
    
- 더 일반적으로 사용됨
    

---

#  envp vs environ 관계 (중요)

##  PDF 핵심 내용

> envp와 environ은 처음에는 같은 위치를 가리킨다

---

##  관계 구조

```text
envp  ─┐
       ├── 동일한 환경변수 영역
environ┘
```

---

##  중요한 차이

|구분|envp|environ|
|---|---|---|
|범위|main 내부|전역|
|변경 반영|❌ 안 됨|⭕ 반영됨|

---

##  핵심 포인트

환경변수가 변경되면:

- `environ` → 변경된 위치 반영
    
- `envp` → 기존 위치 유지
    

---

##  왜 이런 일이 발생하나?

환경변수는 처음에는 **stack에 저장되지만**,  
변경이 발생하면:

 **heap으로 이동할 수 있음**

---

##  결과

```text
초기:
envp == environ

변경 후:
envp ≠ environ
```

---

#  추가 개념: getenv()

---

##  함수

```c
#include <stdlib.h>

char *getenv(const char *name);
```

---

##  사용 예시

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    char *path = getenv("PATH");

    if (path != NULL) {
        printf("PATH=%s\n", path);
    }
}
```

---

##  특징

- 특정 환경변수만 조회 가능
    
- 내부적으로 environ을 사용
    

---

##  PDF 관점 핵심

> getenv()는 환경변수 리스트를 탐색하여 값을 반환한다

---

#  전체 구조 정리

```text
환경변수 접근 방법

1. envp
   - main 내부 전용
   - 초기 상태

2. environ
   - 전역 변수
   - 변경 반영됨

3. getenv()
   - 특정 변수 조회
```

---

#  핵심 요약

```text
envp     → 초기 환경변수 접근
environ  → 전역 접근 + 최신 상태 반영
getenv   → 특정 변수 조회
```
