# 1. 환경변수 개념 (Environment Variables)

---

##  정의

환경변수(Environment Variables)는  
**프로세스가 실행될 때 함께 전달되는 “동적인 이름-값 쌍 (key-value)” 데이터 집합**이다.

- 운영체제의 실행 환경(OS Environment)의 일부
    
- 프로세스마다 독립적으로 존재
    
- 실행 중인 프로그램의 동작 방식에 영향을 줌
    

---

##  핵심 특징

### 1️ 동적(Dynamic)

- 실행 시점마다 값이 달라질 수 있음
    
- 사용자가 직접 설정 가능
    

```bash
export MY_VAR=hello
```

---

### 2️ 프로세스 단위

- 환경변수는 “시스템 전체”가 아니라  
    👉 **각 프로세스에 귀속됨**
    
- 부모 → 자식 프로세스로 전달됨 (fork)
    

---

### 3️ 프로그램 동작에 영향

환경변수는 단순 정보가 아니라  
👉 **프로그램의 실행 방식 자체를 바꾼다**

---

##  대표 예시: PATH

```bash
PATH=/usr/bin:/bin:/usr/local/bin
```

###  역할

- 실행 파일의 위치를 찾기 위한 경로 목록
    

---

###  동작 방식

```bash
ls
```

 실제로는:

```bash
/usr/bin/ls
```

---

###  과정

1. 사용자가 `ls` 입력
    
2. 쉘이 PATH 확인
    
3. 디렉토리 순서대로 탐색
    
4. 실행 파일 발견 → 실행
    

---

##  환경변수의 역할 정리

|역할|설명|
|---|---|
|실행 경로 설정|PATH|
|사용자 정보|HOME, USER|
|프로그램 설정|LANG, LC_ALL|
|시스템 동작 제어|LD_PRELOAD|

---

##  환경변수는 어디서 왔나?

- UNIX에서 처음 도입
    
- 이후 Windows에서도 채택
    

 즉:

> 거의 모든 OS에서 사용하는 기본 메커니즘

---

##  환경변수의 본질

환경변수는 단순한 설정값이 아니라:

```text
프로세스 실행 환경을 구성하는 입력 데이터
```

---

##  중요한 관점 (개발자 관점)

환경변수는:

- 코드 내부 값 ❌
    
- 외부에서 주입되는 값 ⭕
    

 즉:

> 사용자 입력과 동일한 취급이 필요

---

##  보안 관점 핵심

환경변수는 사용자가 설정할 수 있기 때문에:

- 신뢰할 수 없음
    
- 악의적으로 조작 가능
    

 결과:

- 프로그램 동작 변조 가능
    
- 공격 벡터가 될 수 있음
    

---

##  핵심 요약

```text
환경변수 = 프로세스 실행 시 전달되는 key-value 데이터

특징:
- 동적
- 프로세스 단위
- 프로그램 동작에 영향

중요:
- 외부 입력이다
- 신뢰하면 안 된다
```

---

##  한 줄 정리

> 환경변수는 “프로그램을 바꾸는 보이지 않는 입력값”이다
