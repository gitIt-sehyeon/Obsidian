# 6. /proc 파일 시스템

---

## 6.1 개요

`/proc`은 리눅스에서 제공하는 **가상 파일 시스템 (virtual file system)** 이다.

```text
/proc은 실제 디스크에 존재하는 파일이 아니라
커널이 동적으로 생성하는 인터페이스이다
```

---

## 6.2 특징

- 커널 내부 정보 제공
    
- 프로세스 상태 확인 가능
    
- 실시간 데이터 반영
    
- 읽기 전용에 가까운 구조
    

---

## 6.3 프로세스 디렉토리 구조

각 프로세스는 `/proc` 아래에 디렉토리를 가진다:

```bash
/proc/[PID]
```

예:

```bash
/proc/932
```

---

## 6.4 environ 파일 (핵심)

각 프로세스 디렉토리에는 다음 파일이 존재한다:

```bash
/proc/[PID]/environ
```

---

### 역할

```text
해당 프로세스의 환경변수를 저장
```

---

### 예시

```bash
/proc/932/environ
```

→ 프로세스 932의 환경변수

---

## 6.5 현재 프로세스 환경변수 확인

```bash
strings /proc/$$/environ
```

---

### 설명

- `$$` → 현재 shell의 PID
    
- `strings` → 문자열 추출
    

---

### 출력 구조

```text
PATH=/usr/bin
HOME=/home/user
LANG=en_US
```

---

## 6.6 왜 strings를 사용해야 하나

`/proc/[pid]/environ` 파일은:

```text
NULL(\0)로 구분된 문자열
```

즉:

```text
PATH=/usr/bin\0HOME=/home/user\0LANG=en_US\0
```

---

### 문제

일반 cat으로 보면:

```bash
cat /proc/$$/environ
```

→ 한 줄로 붙어서 출력됨

---

### 해결

```bash
strings /proc/$$/environ
```

→ 사람이 읽기 쉬운 형태로 변환

---

## 6.7 env 명령어와의 차이 (중요)

```bash
env
```

---

### PDF 핵심 포인트

```text
env는 새로운 child process에서 실행된다
```

---

### 흐름

```text
shell
  ↓ fork
child process
  ↓ exec(env)
환경변수 출력
```

---

### 결과

```text
env는 shell의 환경변수가 아니라
child process의 환경변수를 출력한다
```

---

## 6.8 핵심 비교

|방법|대상|
|---|---|
|env|자식 프로세스|
|/proc/$$/environ|현재 프로세스|

---

## 6.9 중요한 의미

```text
/proc은 실제 메모리에 존재하는 환경변수를 직접 보여준다
```

---

## 6.10 실습 흐름

### 1. 환경변수 설정

```bash
export TEST=hello
```

---

### 2. env 확인

```bash
env | grep TEST
```

---

### 3. /proc 확인

```bash
strings /proc/$$/environ | grep TEST
```

---

## 6.11 핵심 요약

```text
/proc/[pid]/environ → 실제 환경변수 저장 위치

NULL로 구분된 문자열 구조

strings로 읽어야 함

env는 child process 기준 출력
```

---

## 6.12 한 줄 정리
