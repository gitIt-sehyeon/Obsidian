# 5. shell 변수 vs environment 변수

---

## 5.1 개요

많은 사람들이 다음 두 개를 동일하게 생각하지만, 실제로는 완전히 다르다:

```text
1. shell 변수 (Shell Variable)
2. 환경변수 (Environment Variable)
```

이 차이를 이해해야 프로세스 환경 전달 구조가 정확히 보인다.

---

## 5.2 shell 변수

### 정의

shell 내부에서만 사용하는 변수

---

### 생성

```bash
FOO=bar
```

---

### 특징

- 쉘 내부에서만 존재
    
- 자식 프로세스에 전달되지 않음
    
- export 되지 않으면 외부 프로그램에서 접근 불가
    

---

## 5.3 환경변수

### 정의

프로세스 실행 시 전달되는 변수

---

### 생성

```bash
export FOO=bar
```

---

### 특징

- 자식 프로세스에 전달됨
    
- execve를 통해 프로그램에 전달됨
    
- 실제 프로그램 동작에 영향
    

---

## 5.4 핵심 차이

|구분|shell 변수|환경변수|
|---|---|---|
|범위|shell 내부|프로세스 전체|
|전달|❌ 안 됨|⭕ 전달됨|
|생성|FOO=bar|export FOO=bar|

---

## 5.5 PDF 핵심 동작 흐름

### shell 시작 시

```text
환경변수 → shell 변수로 복사됨
```

---

### 중요한 특징

```text
shell 변수 변경 ≠ 환경변수 변경
```

---

## 5.6 동작 예시 (PDF 구조 설명)

### 단계 1: 환경변수 설정

```bash
export LOGNAME=abc
```

---

### 단계 2: shell 변수 생성

```bash
LOGNAME2=xyz
```

---

### 단계 3: 일부만 export

```bash
export LOGNAME3=hello
```

---

### 단계 4: env 실행

```bash
env
```

---

### 결과 (PDF 핵심 포인트)

```text
LOGNAME   → 전달됨
LOGNAME3  → 전달됨
LOGNAME2  → 전달되지 않음
```

---

## 5.7 왜 이런 결과가 나오나

env 명령어 실행 시:

```text
shell → child process 생성 (fork)
      → execve 실행
```

---

### 전달되는 값

```text
export된 변수만 environment에 포함됨
```

---

### 전달되지 않는 값

```text
단순 shell 변수는 포함되지 않음
```

---

## 5.8 핵심 개념 정리

```text
shell 변수 → shell 내부 상태
환경변수 → 프로세스 전달 데이터
```

---

## 5.9 프로세스 흐름 관점

```text
환경변수
   ↓
shell 시작 시 복사됨
   ↓
shell 변수 생성/수정
   ↓
export된 것만 다시 environment로 이동
   ↓
fork + exec → 자식 프로세스 전달
```

---

## 5.10 중요한 오해

잘못된 생각:

```text
FOO=bar 하면 환경변수도 바뀐다 ❌
```

실제:

```text
FOO=bar → shell 변수만 변경
export FOO → 환경변수로 등록
```

---

## 5.11 핵심 요약

```text
shell 변수는 내부 변수
환경변수는 프로세스 전달용 변수

export를 해야만 전달된다
```

---
