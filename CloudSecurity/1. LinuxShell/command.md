#### 📌 1. 파일 시스템 주요 디렉토리

|디렉토리|내용|
|---|---|
|`/`|최상위 루트|
|`/etc`|시스템 설정 파일 (passwd, shadow 등)|
|`/dev`|물리적 장치 특수 파일|
|`/usr/bin`|기본 쉘 명령어 실행 파일 (ls, mv, cp, pwd 등)|
|`/usr/sbin`|시스템 관리 명령어|
|`/usr/lib`|라이브러리 .so 파일|
|`/home`|일반 사용자 홈 디렉토리|
|`/tmp`|임시 파일 (재부팅 시 삭제 가능)|
|`/var`|시스템 로그|
|`/proc`|실행 중인 프로세스 정보|

#### 📌 3. /etc/passwd 파일 구조

```
root : x : 0 : 0 : root : /root : /bin/bash
 ①    ②   ③   ④    ⑤      ⑥        ⑦
```

|번호|의미|
|---|---|
|①|사용자 계정명|
|②|패스워드 (x = /etc/shadow에 암호화 저장)|
|③|UID (User ID)|
|④|GID (Group ID)|
|⑤|사용자 이름 (시스템 영향 없음)|
|⑥|홈 디렉토리 경로|
|⑦|로그인 쉘 (기본: /bin/bash)|

#### 📌 4. /etc/shadow 파일 구조

패스워드가 **암호화**된 상태로 저장

**암호화 형식:**

```
$algorithm_id $ salt $ hash_value_of_password
```

|algorithm_id|해시 함수|
|---|---|
|1|MD5|
|2|BlowFish|
|5|SHA-256|
|**6**|**SHA-512** (현재 주로 사용)|

**패스워드 특수 상태**

|기호|의미|
|---|---|
|`*`|잠김 (별도 인증으로 로그인 가능)|
|`!`|잠김 (로그인 불가) 또는 패스워드 미설정|

**그 외 필드**

|필드|설명|
|---|---|
|마지막 변경|1970.1.1 기준 일수|
|패스워드 최소 사용기간|변경 후 최소 유지 기간|
|패스워드 최대 사용기간|만료 일수|
|경고|만료 며칠 전 알림|
|비활성화|만료 후 잠기기 전 유예 기간|
|만료일|계정 만료 날짜|

#### 📌 5. 패스워드 검증 과정 ⭐

```
로그인 시 입력한 패스워드 + /etc/shadow의 salt
        ↓
  Crypto hash function (예: SHA-512)
        ↓
  계산된 hash값  ==  /etc/shadow의 hash값?
        ↓
    같으면 로그인 성공
```

**Salt를 사용하는 이유:**

- Salt 없으면 → 같은 패스워드 = 같은 해시 → 공격자가 hash 비교만으로 동일 패스워드 계정 파악 가능
- Salt 있으면 → **레인보우 테이블 공격** 비용이 크게 증가 (패스워드 × 모든 salt 조합을 사전계산해야 함)

#### 📌 6. 파일 권한 (Permission)

**ls -al 출력 예시:**

```
drwxr-xr-x  2  root  root  4096  Mar 10 18:53  alternatives
  ①         ②   ③     ④
```

|번호|의미|
|---|---|
|①|파일 접근 권한|
|②|링크된 파일 수|
|③|소유자|
|④|그룹|

**파일 속성 문자**

|문자|종류|
|---|---|
|`d`|디렉토리|
|`-`|일반 파일|
|`l`|심볼릭 링크|
|`c`|Character 파일 (터미널 등)|
|`b`|Block 파일 (디스크 드라이브 등)|
|`s`|Socket 파일|
|`p`|Pipe 파일|

**권한 구조:**

```
d  rwx  r-x  r-x
   소유자  그룹  Others
```

|권한|문자|숫자|
|---|---|---|
|읽기|r|4|
|쓰기|w|2|
|실행|x|1|

**권한 예시:**

|표기|10진수|의미|
|---|---|---|
|rwxrwxrwx|777|모두 모든 권한|
|rwxr-xr-x|755|소유자 전체, 그룹/Others 읽기+실행|
|rwxr-x--x|751|소유자 전체, 그룹 읽기+실행, Others 실행만|

#### 📌 7. 쉘(Shell) 기본 명령어 모음

|명령어|설명|주요 옵션/예시|
|---|---|---|
|`pwd`|현재 디렉토리 출력||
|`cd`|디렉토리 이동|`cd ..` (상위), `cd /` (루트)|
|`ls`|파일 목록|`-l` (상세), `-a` (숨김파일), `-al` (합쳐서)|
|`mv`|파일 이동/이름 변경|`mv 원본 목적지`|
|`cp`|파일 복사|`cp -r` (디렉토리 포함)|
|`cat`|파일 내용 출력|`cat -n` (행번호 표시)|
|`tail`|파일 끝부분 출력|기본 10행, `-n 5` (5행), `+25` (25행부터 끝까지)|
|`mkdir`|디렉토리 생성|`mkdir -p dir1/subdir1` (하위 포함)|
|`touch`|빈 파일 생성|`touch 파일명`|
|`rm`|파일/디렉토리 삭제|`rm -r` (디렉토리), `rm -rf` (강제)|
|`clear`|쉘 화면 초기화||
|`chown`|소유권자/그룹 변경|`chown 소유자:그룹 파일명`, `-R` (하위 포함)|
|`chmod`|권한 변경|`chmod 755 파일명`|
|`sudo`|root 권한으로 실행|`sudo cat ./a.txt`|
|`id`|현재 사용자 UID/GID 출력|root는 uid=0|
|`echo`|문자열/환경변수 출력|`echo $PATH`|
|`grep`|패턴 검색|`grep 패턴 파일`, `grep 패턴 * -r` (하위 포함)|
|`find`|파일 검색|`-name`, `-type`, `-size`, `-empty`|
|`man`|명령어 사용법 출력|`man ls`|
|`ln -s`|심볼릭 링크 생성|`ln -s 원본 링크파일`|
|`umask`|기본 생성 권한 설정|파일 기본 666, 디렉토리 기본 777에서 umask값 차감|

#### 📌 8. sudo & /etc/sudoers

```
/etc/sudoers  →  누가 어떤 명령에 sudo를 쓸 수 있는지 규칙 정의
```

**규칙 형식:**

```
사용자  호스트=(실행할사용자:그룹)  명령어
```

|예시|의미|
|---|---|
|`shyun ALL=(ALL:ALL) /usr/bin/vi`|shyun이 모든 호스트에서 vi를 root로 실행 가능|
|`%sudo ALL=(ALL:ALL) NOPASSWD:ALL`|sudo 그룹은 패스워드 없이 모든 명령 실행 가능|
|`shyun localhost=(kimh:admin) /sbin/shutdown`|shyun이 localhost에서 kimh 계정으로 shutdown 실행 가능|

#### 📌 9. Redirection & Pipeline

bash

```bash
# Redirection
echo "hello" > file.txt    # 덮어쓰기 (overwrite)
echo "world" >> file.txt   # 이어쓰기 (append)

# Pipeline
ls -l | grep txt           # ls 결과를 grep으로 넘김
```

#### 📌 10. 하드링크 vs 심볼릭링크

| 구분           | 하드링크       | 심볼릭링크         |
| ------------ | ---------- | ------------- |
| inode number | 원본과 **같음** | 원본과 **다름**    |
| 개념           | 디스크상 같은 파일 | 바로가기 파일       |
| 생성           | `ln 원본 링크` | `ln -s 원본 링크` |

#### 📌 시험 자주 나오는 포인트 ⚠️

> **umask 계산:** 파일 666 - umask값, 디렉토리 777 - umask값 ex) umask=002 → 파일 664, 디렉토리 775

> **UID 0 = root** (절대 암기)

> **salt의 목적 = 레인보우 테이블 공격 방어**

> **passwd vs shadow:** passwd는 누구나 읽기 가능, shadow는 암호화된 패스워드 저장 (보안상 분리)
